v68: 브라우저 탭에 센터 아이콘 표시

적용 방법
1. 아래 3개 파일을 기존 프로젝트의 같은 위치에 덮어씁니다.
   index.html
   service-worker.js
   reset-password.html
2. 저장하고 GitHub에 커밋·푸시합니다. 버전 68이 반영되어 있습니다.
   추천 커밋명: v68: 브라우저 탭에 센터 아이콘 추가
3. 배포 후 PC Chrome에서 관리자 탭을 새로고침합니다.
   이전 아이콘이 남으면 해당 탭을 닫고 앱 주소를 새 탭으로 열어 확인합니다.

기존 images/icon-192.png를 그대로 사용하므로 이미지 파일 교체는 필요 없습니다.
모바일 설치 아이콘을 지정하는 manifest.json과 apple-touch-icon 설정은 변경하지 않습니다.
회원/관리자가 같은 index.html을 사용하므로 이 주소의 PC 로그인·회원 탭에도 같은 아이콘이 표시됩니다.
일반 브라우저 탭용 favicon 설정이며 기기 종류로 제한하는 코드는 추가하지 않았습니다.
모바일 브라우저가 탭 목록에 favicon을 표시하는 경우에도 같은 기존 로고를 사용할 수 있습니다.
SQL 실행은 필요 없습니다.

확인 내용
- 기존 PNG 파일의 경로, 192x192 크기, favicon 태그 확인.
- 버전 번호 68 일치 및 manifest.json/앱 JavaScript/이미지 파일 보존 확인.
