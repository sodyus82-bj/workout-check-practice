관리자 루틴 입력 영역 정리

적용 순서
1. 현재 프로젝트를 백업합니다.
2. 이 압축파일의 index.html, style.css, script.js를 현재 프로젝트의 같은 이름 파일에 덮어씁니다.
3. Cursor 미리보기를 새로고침하고 관리자 화면에서 회원을 선택합니다.

exercise-data.js, routine-components.js, service-worker.js는 이번 파일에 포함되지 않습니다.
현재 프로젝트의 해당 파일은 그대로 사용합니다. Supabase SQL 작업은 없습니다.

변경 내용
- 루틴 이름은 공통 입력입니다.
- 운동 카드(JSON) / 기존 이미지 중 선택한 입력 영역만 표시합니다.
- 새 루틴은 운동 카드(JSON)가 기본입니다.
- 기존 루틴은 저장된 방식으로 열립니다. 다른 방식의 새 루틴을 배정하려면 '새 루틴 배정하기'를 누릅니다.
- 새 루틴 작성 중 입력 방식만 바꾸면 이름, JSON, 이미지, 캡션, 설명의 작성 내용은 유지됩니다.
- 입력 방식을 바꾼 뒤 JSON을 적용하려면 다시 검사 및 미리보기를 해야 합니다.
- 회원 변경이나 최신 루틴 수정/새 루틴 배정 전환은 기존과 같이 입력창을 초기화합니다.

확인할 사항
1. JSON 루틴 회원: 이미지/설명 입력 영역이 보이지 않고 저장된 JSON이 표시되는지 확인합니다.
2. 이미지 루틴 회원: 이미지/캡션/설명 영역만 보이고 기존 내용이 유지되는지 확인합니다.
3. 새 루틴 배정: JSON 기본 선택, 두 방식 전환, 전환 후 작성 내용 유지 여부를 확인합니다.
4. 테스트 회원에게 JSON 검사 후 적용하거나 이미지 루틴을 저장하고, 해당 회원 화면에서 확인합니다.

배포 버전
이 파일의 index.html 버전 참조는 기존 v42를 유지했습니다.
로컬 확인 후 v43으로 배포한다면 index.html의 ?v=43 네 곳을 ?v=43으로 변경하고,
현재 service-worker.js의 캐시 이름 및 v42 자원 주소도 v43으로 맞춘 뒤 함께 커밋합니다.
service-worker.js의 나머지 코드는 그대로 유지합니다.

검증 범위
JavaScript 문법, 관리자 입력 방식/조회 상태, 저장 전 검사, 중복 저장 방지 등을 모의 환경에서 확인했습니다.
실제 Supabase 저장과 모바일 화면은 사용자 환경에서 확인해 주세요.
